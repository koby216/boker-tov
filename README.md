# בוקר טוב

אפליקציה לאנדרואיד שמאפשרת לשלוט בטלפון בקול בלבד, בלי ידיים.

## איך משתמשים
1. מתקינים ופותחים את האפליקציה.
2. מסדרים את הרשימה שבמסך הראשון (הרשאות, נגישות, הודעות וואטסאפ, סוללה).
3. לוחצים **הפעל**.
4. אומרים **"בוקר טוב"** (או "בוקר טוב" ושם, אם בחרתם שם) ואז את הבקשה.

## מה אפשר להגיד
- תתקשר לדני / ענה לשיחה / דחה שיחה
- תשלח לדני אני בדרך (שואלת לפני שליחה)
- נווט הביתה / נווט לתל אביב
- נגן מוזיקה / עצור מוזיקה / השיר הבא
- מה השעה / איזה יום היום
- תעיר אותי בשבע וחצי / תזכיר לי בעוד עשר דקות
- הגבר / הנמך / השתק, פנס
- גלול למטה / חזור / בית / פתח יוטיוב / לחץ על ... / הקלד ...
- מה על המסך / תקריא הודעות
- ביטול (עוצר בכל רגע)

## בטיחות
- אפליקציות של בנקים, תשלומים, סיסמאות, דואר אלקטרוני וקניות חסומות לגמרי.
- שליטה במסך פועלת רק באפליקציות ברשימה מאושרת (`AppPolicy` בקוד).
- פעולות רגישות (שליחה, מחיקה, תשלום) דורשות אישור בקול.
- ברכב (בלוטות' או מצב רכב) שליטה במסך כבויה.

## בנייה
GitHub Actions בונה קובץ התקנה בכל העלאה: לשונית **Actions**, ההרצה האחרונה, **Artifacts**, `boker-tov-apk`.
